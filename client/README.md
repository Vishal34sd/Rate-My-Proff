# 🎨 Rate My Proff — Client Application

The modern React 19 frontend for **Rate My Proff**, powered by Vite, Tailwind CSS v4, and Framer Motion.

For full project documentation, architecture, API reference, and team details, please see the [Root README](../README.md).

## Quick Start

```bash
# Install dependencies
npm install

# Run Vite dev server
npm run dev

# Run production build
npm run build

# Run linter
npm run lint
```
